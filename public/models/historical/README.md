# Historical 3D model assets

Each folder under this directory is one historically-inspired 3D site used by
the `HistoricalScene` pipeline. The app ships without the actual model files
and runs a clearly-labeled procedural fallback until a licensed, web-optimized
asset is dropped in at the documented path — see each site's `README.md` for
the exact required file name, placement and tuning notes.

- `pratapgad/` — expected `pratapgad.glb`; drive by `data/sites.json`.
